## 커뮤니티 : The Hazel Grove 
### 💁 Introduce
`The Hazel Grove`는 사용자가 게시글을 작성하고 댓글을 달며 소통할 수 있는 커뮤니티 웹 애플리케이션입니다.

## ✨ Main features
### 📝 게시글 관리 
- 게시글 작성, 수정, 삭제
- 게시글 상세 페이지: 좋아요, 댓글 확인, 조회수 집계
### 👤 유저 관리 
- 회원가입 및 로그인
- 사용자 정보 수정
- 비밀번호 변경
- 회원 탈퇴
### 💬 댓글 관리 
- 댓글 작성, 수정, 삭제

<br>

## 🚀 Starting Guide
### ⚙️ 의존성 설치
`npm install`
### 🖥️ 프론트엔드 
`node server.js`
### 🛠️ 백엔드 
`node index.js`
### 🔗 접속 링크
`http://localhost:3000`

<br>

## 📂 Short Directory
- api/: API 라우트
- data/: JSON 더미 데이터 
- scripts/: 프론트엔드 JavaScript 로직
- style/: CSS 스타일
- utils/: 유틸리티 함수
